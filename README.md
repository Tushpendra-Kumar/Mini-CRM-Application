## 📌 Overview

A full-stack Customer Relationship Management (CRM) dashboard designed for managing client leads, contact directories, sales pipeline progression, and client interaction records.

---

## ✨ Key Features

- **Client & Lead Management:** Add, edit, inspect, and delete customer records with contact details and company profiles.
- **Pipeline Status Funnel:** Categorize clients across New, Contacted, In-Discussion, and Closed statuses.
- **RESTful Backend API:** Node.js Express server delivering structured JSON endpoints for customer CRUD operations.
- **Clean Dashboard UI:** Responsive analytical cards displaying key client KPIs and summaries.

---

## 💻 Tech Stack & Architecture

- **Backend Architecture:** Node.js, Express.js, REST API Middleware
- **Frontend:** HTML5, Modern CSS3, JavaScript Fetch API

## 🚀 Getting Started

### Prerequisites
Node.js v16+ and npm.

### Installation & Setup
```bash
# 1. Clone this repository
git clone https://github.com/Tushpendra-Kumar/Mini-CRM-Application.git

# 2. Navigate into project directory
cd Mini-CRM-Application

# 3. Install packages
npm install

# 4. Start backend server
node backend/index.js
```
